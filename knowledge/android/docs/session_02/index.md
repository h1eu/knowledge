# Session 02: Hệ điều hành & Quyền

## Giới thiệu

Session 02 tìm hiểu về cách **hệ điều hành Android** quản lý quyền truy cập, tiến trình, tài nguyên và mô hình đa người dùng. Đây là kiến thức nền tảng để hiểu vì sao Android hoạt động như một hệ điều hành đặc thù.

## Nội dung Session

- [2.1 File Permissions](file_permissions.md)
- 2.2 Process Management (chưa có bài)
- 2.3 Resource Solutions (chưa có bài)
- 2.4 Multi User OS (chưa có bài)

## Học tiếp

Sau khi hiểu cách Android quản lý hệ thống, bạn sẽ tìm hiểu về phần cứng và kernel trong Session 03.

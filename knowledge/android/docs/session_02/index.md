# Session 02: Hệ điều hành & Quyền

## Giới thiệu

Session 02 tìm hiểu về cách **hệ điều hành Android** quản lý quyền truy cập, tiến trình, tài nguyên và mô hình đa người dùng. Đây là kiến thức nền tảng để hiểu vì sao Android hoạt động như một hệ điều hành đặc thù.

## 📋 Đề bài

<div class="lc-description"><p>Cho mảng <code>nums</code> độ dài <code>n</code> và số nguyên <code>target</code>, hãy tìm tất cả bộ bốn khác nhau sao cho tổng bằng <code>target</code>. Đáp án không chứa bộ trùng.</p>

<p>Có thể trả về theo bất kỳ thứ tự nào.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums = [1,0,-1,0,-2,2], target = 0
<strong>Đầu ra:</strong> [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums = [2,2,2,2,2], target = 8
<strong>Đầu ra:</strong> [[2,2,2,2]]
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 200</code></li>
	<li><code>-10<sup>9</sup> &lt;= nums[i] &lt;= 10<sup>9</sup></code></li>
	<li><code>-10<sup>9</sup> &lt;= target &lt;= 10<sup>9</sup></code></li>
</ul>

</div>

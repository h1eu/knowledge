## 📋 Đề bài

<div class="lc-description"><p>Chuỗi là palindrome nếu đọc xuôi ngược như nhau sau khi chuyển mọi chữ hoa thành chữ thường và chỉ giữ ký tự chữ-số (alphanumeric).</p>

<p>Cho chuỗi <code>s</code>, hãy trả về <code>true</code> nếu là palindrome, ngược lại <code>false</code>.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;A man, a plan, a canal: Panama&quot;
<strong>Đầu ra:</strong> true
<strong>Giải thích:</strong> &quot;amanaplanacanalpanama&quot; is a palindrome.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;race a car&quot;
<strong>Đầu ra:</strong> false
<strong>Giải thích:</strong> &quot;raceacar&quot; is not a palindrome.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot; &quot;
<strong>Đầu ra:</strong> true
<strong>Giải thích:</strong> s is an empty string &quot;&quot; after removing non-alphanumeric characters.
Since an empty string reads the same forward and backward, it is a palindrome.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= s.length &lt;= 2 * 10<sup>5</sup></code></li>
	<li><code>s</code> consists only of printable ASCII characters.</li>
</ul>

</div>

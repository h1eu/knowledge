# 345. Reverse Vowels of a String

## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi <code>s</code>, chỉ đảo ngược các nguyên âm (<code>a, e, i, o, u</code> cả hoa thường) và giữ nguyên các ký tự còn lại. Hãy trả về chuỗi sau khi đảo.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<div class="example-block">
<p><strong>Đầu vào:</strong> <span class="example-io">s = &quot;IceCreAm&quot;</span></p>

<p><strong>Đầu ra:</strong> <span class="example-io">&quot;AceCreIm&quot;</span></p>

<p><strong>Giải thích:</strong></p>

<p>The vowels in <code>s</code> are <code>[&#39;I&#39;, &#39;e&#39;, &#39;e&#39;, &#39;A&#39;]</code>. On reversing the vowels, s becomes <code>&quot;AceCreIm&quot;</code>.</p>
</div>

<p><strong class="example">Example 2:</strong></p>

<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">s = &quot;leetcode&quot;</span></p>

<p><strong>Output:</strong> <span class="example-io">&quot;leotcede&quot;</span></p>
</div>

<p>&nbsp;</p>
<p><strong>Constraints:</strong></p>

<ul>
	<li><code>1 &lt;= s.length &lt;= 3 * 10<sup>5</sup></code></li>
	<li><code>s</code> consist of <strong>printable ASCII</strong> characters.</li>
</ul>

</div>

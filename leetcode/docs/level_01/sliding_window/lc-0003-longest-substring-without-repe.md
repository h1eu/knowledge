# 3. Longest Substring Without Repeating Characters

<div class="lc-problem-header">
  <span class="lc-pill lc-pill-medium">Medium</span> <span class="lc-pill lc-pill-pattern">Sliding Window</span> <span class="lc-pill lc-pill-level">Level 1</span> <a href="https://leetcode.com/problems/longest-substring-without-repeating-characters/" target="_blank">LeetCode 3 ↗</a>

## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi <code>s</code>, hãy tìm độ dài của <strong>chuỗi con dài nhất</strong> không chứa ký tự lặp lại.</p>

<p>Chuỗi con là dãy liên tiếp các ký tự.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;abcabcbb&quot;
<strong>Đầu ra:</strong> 3
<strong>Giải thích:</strong> The answer is &quot;abc&quot;, with the length of 3. Note that <code>&quot;bca&quot;</code> and <code>&quot;cab&quot;</code> are also correct answers.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;bbbbb&quot;
<strong>Đầu ra:</strong> 1
<strong>Giải thích:</strong> The answer is &quot;b&quot;, with the length of 1.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;pwwkew&quot;
<strong>Đầu ra:</strong> 3
<strong>Giải thích:</strong> The answer is &quot;wke&quot;, with the length of 3.
Notice that the answer must be a substring, &quot;pwke&quot; is a subsequence and not a substring.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>0 &lt;= s.length &lt;= 10<sup>5</sup></code></li>
	<li><code>s</code> consists of English letters, digits, symbols and spaces.</li>
</ul>

</div>

# 1456. Maximum Number of Vowels in a Substring of Given Length

## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi <code>s</code> và số nguyên <code>k</code>, hãy trả về số lượng nguyên âm lớn nhất trong bất kỳ chuỗi con (substring) nào có độ dài <code>k</code> của <code>s</code>.</p>

<p>Nguyên âm là <code>'a', 'e', 'i', 'o', 'u'</code>.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;abciiidef&quot;, k = 3
<strong>Đầu ra:</strong> 3
<strong>Giải thích:</strong> The substring &quot;iii&quot; contains 3 vowel letters.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;aeiou&quot;, k = 2
<strong>Đầu ra:</strong> 2
<strong>Giải thích:</strong> Any substring of length 2 contains 2 vowels.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;leetcode&quot;, k = 3
<strong>Đầu ra:</strong> 2
<strong>Giải thích:</strong> &quot;lee&quot;, &quot;eet&quot; and &quot;ode&quot; contain 2 vowels.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= s.length &lt;= 10<sup>5</sup></code></li>
	<li><code>s</code> consists of lowercase English letters.</li>
	<li><code>1 &lt;= k &lt;= s.length</code></li>
</ul>

</div>

## 📋 Đề bài

<div class="lc-description"><p>Cho số nguyên <code>rowIndex</code>, hãy trả về hàng thứ <code>rowIndex</code> của tam giác Pascal (đánh chỉ số từ 0).</p>

<p>Yêu cầu tối ưu bộ nhớ <code>O(rowIndex)</code>.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>
<pre><strong>Đầu vào:</strong> rowIndex = 3
<strong>Đầu ra:</strong> [1,3,3,1]
</pre><p><strong class="example">Ví dụ 2:</strong></p>
<pre><strong>Đầu vào:</strong> rowIndex = 0
<strong>Đầu ra:</strong> [1]
</pre><p><strong class="example">Ví dụ 3:</strong></p>
<pre><strong>Đầu vào:</strong> rowIndex = 1
<strong>Đầu ra:</strong> [1,1]
</pre>
<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>0 &lt;= rowIndex &lt;= 33</code></li>
</ul>

<p>&nbsp;</p>
<p><strong>Yêu cầu mở rộng:</strong> Could you optimize your algorithm to use only <code>O(rowIndex)</code> extra space?</p>

</div>

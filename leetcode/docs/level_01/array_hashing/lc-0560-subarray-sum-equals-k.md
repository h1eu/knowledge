## 📋 Đề bài

<div class="lc-description"><p>Cho mảng số nguyên <code>nums</code> và số nguyên <code>k</code>, hãy trả về số lượng mảng con liên tiếp có tổng bằng <code>k</code>.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>
<pre><strong>Đầu vào:</strong> nums = [1,1,1], k = 2
<strong>Đầu ra:</strong> 2
</pre><p><strong class="example">Ví dụ 2:</strong></p>
<pre><strong>Đầu vào:</strong> nums = [1,2,3], k = 3
<strong>Đầu ra:</strong> 2
</pre>
<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 2 * 10<sup>4</sup></code></li>
	<li><code>-1000 &lt;= nums[i] &lt;= 1000</code></li>
	<li><code>-10<sup>7</sup> &lt;= k &lt;= 10<sup>7</sup></code></li>
</ul>

# 374. Guess Number Higher or Lower

## 📋 Đề bài

<div class="lc-description"><p>Ta chọn một số trong khoảng <code>[1, n]</code>. Bạn đoán số bằng cách gọi API <code>guess(num)</code>:</p>

<ul>
	<li><code>-1</code> nếu số bạn đoán lớn hơn số đã chọn (<code>num > pick</code>).</li>
	<li><code>1</code> nếu số bạn đoán nhỏ hơn số đã chọn (<code>num < pick</code>).</li>
	<li><code>0</code> nếu bằng (<code>num == pick</code>).</li>
</ul>

<p>Hãy trả về số đã chọn.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> n = 10, pick = 6
<strong>Đầu ra:</strong> 6
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> n = 1, pick = 1
<strong>Đầu ra:</strong> 1
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> n = 2, pick = 1
<strong>Đầu ra:</strong> 1
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= n &lt;= 2<sup>31</sup> - 1</code></li>
	<li><code>1 &lt;= pick &lt;= n</code></li>
</ul>

</div>

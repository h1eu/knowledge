## 📋 Đề bài

<div class="lc-description"><p>Phần tử đỉnh (peak) là phần tử <strong>lớn hơn nghiêm ngặt</strong> các phần tử kề nó.</p>

<p>Cho mảng số nguyên <code>nums</code> (các phần tử kề nhau được đảm bảo khác nhau), hãy tìm một phần tử đỉnh và trả về chỉ số của nó.</p>

<p>Nếu mảng chỉ có một phần tử, nó là đỉnh. Bạn có thể giả định <code>nums[-1] = nums[n] = -∞</code>.</p>

<p>Bạn phải viết thuật toán có độ phức tạp <code>O(log n)</code>.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums = [1,2,3,1]
<strong>Đầu ra:</strong> 2
<strong>Giải thích:</strong> 3 is a peak element and your function should return the index number 2.</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums = [1,2,1,3,5,6,4]
<strong>Đầu ra:</strong> 5
<strong>Giải thích:</strong> Your function can return either index number 1 where the peak element is 2, or index number 5 where the peak element is 6.</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= nums.length &lt;= 1000</code></li>
	<li><code>-2<sup>31</sup> &lt;= nums[i] &lt;= 2<sup>31</sup> - 1</code></li>
	<li><code>nums[i] != nums[i + 1]</code> for all valid <code>i</code>.</li>
</ul>

</div>

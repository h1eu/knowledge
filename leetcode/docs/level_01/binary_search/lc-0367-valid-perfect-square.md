## 📋 Đề bài

<div class="lc-description"><p>Cho số nguyên dương <code>num</code>, hãy trả về <code>true</code> nếu <code>num</code> là số chính phương, ngược lại <code>false</code>.</p>

<p>Số chính phương là số nguyên có thể biểu diễn thành tích của một số nguyên với chính nó, ví dụ <code>16 = 4 * 4</code>.</p>

<p>Không được sử dụng hàm căn bậc hai có sẵn như <code>sqrt</code>.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> num = 16
<strong>Đầu ra:</strong> true
<strong>Giải thích:</strong> We return true because 4 * 4 = 16 and 4 is an integer.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> num = 14
<strong>Đầu ra:</strong> false
<strong>Giải thích:</strong> We return false because 3.742 * 3.742 = 14 and 3.742 is not an integer.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= num &lt;= 2<sup>31</sup> - 1</code></li>
</ul>

</div>

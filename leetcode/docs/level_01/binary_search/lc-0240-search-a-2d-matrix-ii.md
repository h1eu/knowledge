## 📋 Đề bài

<div class="lc-description"><p>Hãy viết thuật toán hiệu quả để tìm giá trị <code>target</code> trong ma trận nguyên <code>m x n</code> <code>matrix</code>. Ma trận có các tính chất sau:</p>

<ul>
	<li>Số nguyên trong mỗi hàng được sắp xếp tăng dần từ trái sang phải.</li>
	<li>Số nguyên trong mỗi cột được sắp xếp tăng dần từ trên xuống dưới.</li>
</ul>

	<li><code>n == matrix[i].length</code></li>

	<li><code>-10<sup>9</sup> &lt;= matrix[i][j] &lt;= 10<sup>9</sup></code></li>
	<li>All the integers in each row are <strong>sorted</strong> in ascending order.</li>
	<li>All the integers in each column are <strong>sorted</strong> in ascending order.</li>

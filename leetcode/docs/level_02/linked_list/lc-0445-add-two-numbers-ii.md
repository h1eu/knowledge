## 📋 Đề bài

<div class="lc-description"><p>Cho hai danh sách liên kết <code>l1</code> và <code>l2</code> biểu diễn hai số nguyên không âm, các chữ số lưu theo thứ tự xuôi (đầu là chữ số cao nhất). Hãy cộng và trả về tổng dưới dạng danh sách liên kết (cũng xuôi).</p>

<p>Không được đảo ngược danh sách đầu vào.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>
<img alt="" src="https://assets.leetcode.com/uploads/2021/04/09/sumii-linked-list.jpg" style="width: 523px; height: 342px;" />
<pre>
<strong>Đầu vào:</strong> l1 = [7,2,4,3], l2 = [5,6,4]
<strong>Đầu ra:</strong> [7,8,0,7]
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> l1 = [2,4,3], l2 = [5,6,4]
<strong>Đầu ra:</strong> [8,0,7]
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> l1 = [0], l2 = [0]
<strong>Đầu ra:</strong> [0]
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li>The number of nodes in each linked list is in the range <code>[1, 100]</code>.</li>
	<li><code>0 &lt;= Node.val &lt;= 9</code></li>
	<li>It is guaranteed that the list represents a number that does not have leading zeros.</li>
</ul>

<p>&nbsp;</p>
<p><strong>Yêu cầu mở rộng:</strong>&nbsp;Could you solve it without reversing the input lists?</p>

</div>

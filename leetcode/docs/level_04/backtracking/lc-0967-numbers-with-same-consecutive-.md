# 967. Numbers With Same Consecutive Differences

## 📋 Đề bài

<div class="lc-description"><p>Cho hai số nguyên <code>n</code> và <code>k</code>, hãy trả về tất cả các số có <code>n</code> chữ số mà hiệu tuyệt đối giữa hai chữ số liên tiếp đúng bằng <code>k</code>.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> n = 3, k = 7
<strong>Đầu ra:</strong> [181,292,707,818,929]
<strong>Giải thích:</strong> Note that 070 is not a valid number, because it has leading zeroes.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> n = 2, k = 1
<strong>Đầu ra:</strong> [10,12,21,23,32,34,43,45,54,56,65,67,76,78,87,89,98]
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>2 &lt;= n &lt;= 9</code></li>
	<li><code>0 &lt;= k &lt;= 9</code></li>
</ul>

</div>

## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi <code>s</code>, hãy phân hoạch <code>s</code> sao cho mỗi chuỗi con đều là palindrome, trả về tất cả các cách phân hoạch.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>
<pre><strong>Đầu vào:</strong> s = "aab"
<strong>Đầu ra:</strong> [["a","a","b"],["aa","b"]]
</pre><p><strong class="example">Ví dụ 2:</strong></p>
<pre><strong>Đầu vào:</strong> s = "a"
<strong>Đầu ra:</strong> [["a"]]
</pre>
<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= s.length &lt;= 16</code></li>
	<li><code>s</code> contains only lowercase English letters.</li>
</ul>

</div>

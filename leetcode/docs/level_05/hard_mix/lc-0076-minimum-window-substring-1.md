# 76. Minimum Window Substring

## 📋 Đề bài

<div class="lc-description"><p>Cho hai chuỗi <code>s</code> và <code>t</code>, hãy tìm cửa sổ con nhỏ nhất của <code>s</code> chứa mọi ký tự của <code>t</code> (bản Hard Mix).</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;ADOBECODEBANC&quot;, t = &quot;ABC&quot;
<strong>Đầu ra:</strong> &quot;BANC&quot;
<strong>Giải thích:</strong> The minimum window substring &quot;BANC&quot; includes &#39;A&#39;, &#39;B&#39;, and &#39;C&#39; from string t.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;a&quot;, t = &quot;a&quot;
<strong>Đầu ra:</strong> &quot;a&quot;
<strong>Giải thích:</strong> The entire string s is the minimum window.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;a&quot;, t = &quot;aa&quot;
<strong>Đầu ra:</strong> &quot;&quot;
<strong>Giải thích:</strong> Both &#39;a&#39;s from t must be included in the window.
Since the largest window of s only has one &#39;a&#39;, return empty string.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>m == s.length</code></li>
	<li><code>n == t.length</code></li>
	<li><code>1 &lt;= m, n &lt;= 10<sup>5</sup></code></li>
	<li><code>s</code> and <code>t</code> consist of uppercase and lowercase English letters.</li>
</ul>

<p>&nbsp;</p>
<p><strong>Yêu cầu mở rộng:</strong> Could you find an algorithm that runs in <code>O(m + n)</code> time?</p>

</div>

## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi chỉ chứa <code>'('</code> và <code>')'</code>, hãy tìm độ dài chuỗi con ngoặc hợp lệ dài nhất.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;(()&quot;
<strong>Đầu ra:</strong> 2
<strong>Giải thích:</strong> The longest valid parentheses substring is &quot;()&quot;.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;)()())&quot;
<strong>Đầu ra:</strong> 4
<strong>Giải thích:</strong> The longest valid parentheses substring is &quot;()()&quot;.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;&quot;
<strong>Đầu ra:</strong> 0
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>0 &lt;= s.length &lt;= 3 * 10<sup>4</sup></code></li>
	<li><code>s[i]</code> is <code>&#39;(&#39;</code>, or <code>&#39;)&#39;</code>.</li>
</ul>

</div>

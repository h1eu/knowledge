## 📋 Đề bài

<div class="lc-description"><p>Cho số nguyên <code>x</code>, hãy trả về <code>true</code> nếu <code>x</code> là palindrome (đọc xuôi ngược như nhau).</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> x = 121
<strong>Đầu ra:</strong> true
<strong>Giải thích:</strong> 121 reads as 121 from left to right and from right to left.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> x = -121
<strong>Đầu ra:</strong> false
<strong>Giải thích:</strong> From left to right, it reads -121. From right to left, it becomes 121-. Therefore it is not a palindrome.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> x = 10
<strong>Đầu ra:</strong> false
<strong>Giải thích:</strong> Reads 01 from right to left. Therefore it is not a palindrome.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>-2<sup>31</sup>&nbsp;&lt;= x &lt;= 2<sup>31</sup>&nbsp;- 1</code></li>
</ul>

<p>&nbsp;</p>
<strong>Yêu cầu mở rộng:</strong> Could you solve it without converting the integer to a string?
</div>

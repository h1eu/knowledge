## 📋 Đề bài

<div class="lc-description"><p>Cho hai chuỗi số <code>num1</code> và <code>num2</code> biểu diễn số nguyên không âm, hãy trả về tích của chúng dưới dạng chuỗi.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>
<pre><strong>Đầu vào:</strong> num1 = "2", num2 = "3"
<strong>Đầu ra:</strong> "6"
</pre><p><strong class="example">Ví dụ 2:</strong></p>
<pre><strong>Đầu vào:</strong> num1 = "123", num2 = "456"
<strong>Đầu ra:</strong> "56088"
</pre>
<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= num1.length, num2.length &lt;= 200</code></li>
	<li><code>num1</code> and <code>num2</code> consist of digits only.</li>
	<li>Both <code>num1</code> and <code>num2</code>&nbsp;do not contain any leading zero, except the number <code>0</code> itself.</li>
</ul>

</div>

## 📋 Đề bài

<div class="lc-description"><p>Cho số nguyên 32-bit <code>x</code>, hãy đảo ngược chữ số, nếu vượt ngoài <code>[-2<sup>31</sup>, 2<sup>31</sup>-1]</code> thì trả về <code>0</code>.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> x = 123
<strong>Đầu ra:</strong> 321
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> x = -123
<strong>Đầu ra:</strong> -321
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> x = 120
<strong>Đầu ra:</strong> 21
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>-2<sup>31</sup> &lt;= x &lt;= 2<sup>31</sup> - 1</code></li>
</ul>

</div>

## 📋 Đề bài

<div class="lc-description"><p>Cho số nguyên không âm <code>x</code>, hãy trả về căn bậc hai làm tròn xuống (bản Math).</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> x = 4
<strong>Đầu ra:</strong> 2
<strong>Giải thích:</strong> The square root of 4 is 2, so we return 2.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> x = 8
<strong>Đầu ra:</strong> 2
<strong>Giải thích:</strong> The square root of 8 is 2.82842..., and since we round it down to the nearest integer, 2 is returned.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>0 &lt;= x &lt;= 2<sup>31</sup> - 1</code></li>
</ul>

## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi <code>s</code>, hãy tìm số lần chèn ít nhất để biến <code>s</code> thành palindrome (có thể chèn ở bất kỳ vị trí nào).</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;zzazz&quot;
<strong>Đầu ra:</strong> 0
<strong>Giải thích:</strong> The string &quot;zzazz&quot; is already palindrome we do not need any insertions.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;mbadm&quot;
<strong>Đầu ra:</strong> 2
<strong>Giải thích:</strong> String can be &quot;mbdadbm&quot; or &quot;mdbabdm&quot;.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;leetcode&quot;
<strong>Đầu ra:</strong> 5
<strong>Giải thích:</strong> Inserting 5 characters the string becomes &quot;leetcodocteel&quot;.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= s.length &lt;= 500</code></li>
	<li><code>s</code> consists of lowercase English letters.</li>
</ul>

</div>

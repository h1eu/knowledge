## 📋 Đề bài

<div class="lc-description"><p>Cho mảng phong bì <code>envelopes</code> với <code>[w,h]</code>, một phong bì có thể lồng vào phong bì khác nếu cả chiều rộng và cao đều lớn hơn. Hãy tìm số phong bì lồng nhau tối đa.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> envelopes = [[5,4],[6,4],[6,7],[2,3]]
<strong>Đầu ra:</strong> 3
<strong>Giải thích:</strong> The maximum number of envelopes you can Russian doll is <code>3</code> ([2,3] =&gt; [5,4] =&gt; [6,7]).
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> envelopes = [[1,1],[1,1],[1,1]]
<strong>Đầu ra:</strong> 1
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= envelopes.length &lt;= 10<sup>5</sup></code></li>
	<li><code>envelopes[i].length == 2</code></li>
	<li><code>1 &lt;= w<sub>i</sub>, h<sub>i</sub> &lt;= 10<sup>5</sup></code></li>
</ul>

</div>

## 📋 Đề bài

<div class="lc-description"><p>Cho ma trận <code>m x n</code>, hãy tìm độ dài đường đi tăng dài nhất (di chuyển 4 hướng, giá trị tăng nghiêm ngặt).</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>

<strong>Đầu ra:</strong> 4
<strong>Giải thích:</strong> The longest increasing path is <code>[1, 2, 6, 9]</code>.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>
<img alt="" src="https://assets.leetcode.com/uploads/2021/01/27/tmp-grid.jpg" style="width: 253px; height: 253px;" />

<strong>Đầu ra:</strong> 4
<strong>Giải thích: </strong>The longest increasing path is <code>[3, 4, 5, 6]</code>. Moving diagonally is not allowed.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>

<ul>

	<li><code>n == matrix[i].length</code></li>
	<li><code>1 &lt;= m, n &lt;= 200</code></li>
	<li><code>0 &lt;= matrix[i][j] &lt;= 2<sup>31</sup> - 1</code></li>
</ul>

## 📋 Đề bài

<div class="lc-description"><p>Cho mảng thanh <code>rods</code>, hãy dùng một số thanh tạo hai giá đỡ có chiều cao bằng nhau và lớn nhất, phần còn lại bỏ.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> rods = [1,2,3,6]
<strong>Đầu ra:</strong> 6
<strong>Giải thích:</strong> We have two disjoint subsets {1,2,3} and {6}, which have the same sum = 6.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> rods = [1,2,3,4,5,6]
<strong>Đầu ra:</strong> 10
<strong>Giải thích:</strong> We have two disjoint subsets {2,3,5} and {4,6}, which have the same sum = 10.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> rods = [1,2]
<strong>Đầu ra:</strong> 0
<strong>Giải thích:</strong> The billboard cannot be supported, so we return 0.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= rods.length &lt;= 20</code></li>
	<li><code>1 &lt;= rods[i] &lt;= 1000</code></li>
	<li><code>sum(rods[i]) &lt;= 5000</code></li>
</ul>

</div>

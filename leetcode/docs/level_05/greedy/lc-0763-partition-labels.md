## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi <code>s</code>, hãy chia thành nhiều phần nhất sao cho mỗi chữ cái chỉ xuất hiện trong một phần, trả về độ dài các phần.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;ababcbacadefegdehijhklij&quot;
<strong>Đầu ra:</strong> [9,7,8]
<strong>Giải thích:</strong>
The partition is &quot;ababcbaca&quot;, &quot;defegde&quot;, &quot;hijhklij&quot;.
This is a partition so that each letter appears in at most one part.
A partition like &quot;ababcbacadefegde&quot;, &quot;hijhklij&quot; is incorrect, because it splits s into less parts.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;eccbbbbdec&quot;
<strong>Đầu ra:</strong> [10]
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= s.length &lt;= 500</code></li>
	<li><code>s</code> consists of lowercase English letters.</li>
</ul>

</div>

## 📋 Đề bài

<div class="lc-description"><p>Cho hai mảng <code>nums1</code>, <code>nums2</code> và số nguyên <code>k</code>, hãy tạo số lớn nhất độ dài <code>k</code> bằng cách chọn dãy con từ hai mảng và trộn.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums1 = [3,4,6,5], nums2 = [9,1,2,5,8,3], k = 5
<strong>Đầu ra:</strong> [9,8,6,5,3]
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums1 = [6,7], nums2 = [6,0,4], k = 5
<strong>Đầu ra:</strong> [6,7,6,0,4]
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums1 = [3,9], nums2 = [8,9], k = 3
<strong>Đầu ra:</strong> [9,8,9]
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>m == nums1.length</code></li>
	<li><code>n == nums2.length</code></li>
	<li><code>1 &lt;= m, n &lt;= 500</code></li>
	<li><code>0 &lt;= nums1[i], nums2[i] &lt;= 9</code></li>
	<li><code>1 &lt;= k &lt;= m + n</code></li>
	<li><code>nums1</code> and <code>nums2</code> do not have leading zeros.</li>
</ul>

</div>

## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi <code>s</code> chứa <code>'('</code>, <code>')'</code> và <code>'*'</code> (có thể là <code>'('</code>, <code>')'</code> hoặc rỗng), hãy xác định chuỗi có thể hợp lệ không.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>
<pre><strong>Đầu vào:</strong> s = "()"
<strong>Đầu ra:</strong> true
</pre><p><strong class="example">Ví dụ 2:</strong></p>
<pre><strong>Đầu vào:</strong> s = "(*)"
<strong>Đầu ra:</strong> true
</pre><p><strong class="example">Ví dụ 3:</strong></p>
<pre><strong>Đầu vào:</strong> s = "(*))"
<strong>Đầu ra:</strong> true
</pre>
<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= s.length &lt;= 100</code></li>
	<li><code>s[i]</code> is <code>&#39;(&#39;</code>, <code>&#39;)&#39;</code> or <code>&#39;*&#39;</code>.</li>
</ul>

</div>

# 402. Remove K Digits

## 📋 Đề bài

<div class="lc-description"><p>Cho chuỗi số <code>num</code> và số nguyên <code>k</code>, hãy xóa <code>k</code> chữ số để số còn lại nhỏ nhất, trả về dưới dạng chuỗi.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> num = &quot;1432219&quot;, k = 3
<strong>Đầu ra:</strong> &quot;1219&quot;
<strong>Giải thích:</strong> Remove the three digits 4, 3, and 2 to form the new number 1219 which is the smallest.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> num = &quot;10200&quot;, k = 1
<strong>Đầu ra:</strong> &quot;200&quot;
<strong>Giải thích:</strong> Remove the leading 1 and the number is 200. Note that the output must not contain leading zeroes.
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> num = &quot;10&quot;, k = 2
<strong>Đầu ra:</strong> &quot;0&quot;
<strong>Giải thích:</strong> Remove all the digits from the number and it is left with nothing which is 0.
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>1 &lt;= k &lt;= num.length &lt;= 10<sup>5</sup></code></li>
	<li><code>num</code> consists of only digits.</li>
	<li><code>num</code> does not have any leading zeros except for the zero itself.</li>
</ul>

</div>

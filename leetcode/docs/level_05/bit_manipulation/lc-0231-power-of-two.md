## 📋 Đề bài

<div class="lc-description"><p>Cho số nguyên <code>n</code>, hãy trả về <code>true</code> nếu <code>n</code> là lũy thừa của 2.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> n = 1
<strong>Đầu ra:</strong> true
<strong>Giải thích: </strong>2<sup>0</sup> = 1
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> n = 16
<strong>Đầu ra:</strong> true
<strong>Giải thích: </strong>2<sup>4</sup> = 16
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> n = 3
<strong>Đầu ra:</strong> false
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>-2<sup>31</sup> &lt;= n &lt;= 2<sup>31</sup> - 1</code></li>
</ul>

<p>&nbsp;</p>
<strong>Yêu cầu mở rộng:</strong> Could you solve it without loops/recursion?
</div>

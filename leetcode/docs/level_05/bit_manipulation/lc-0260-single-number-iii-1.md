## 📋 Đề bài

<div class="lc-description"><p>Cho mảng <code>nums</code> với đúng hai phần tử chỉ xuất hiện một lần, còn lại xuất hiện hai lần, hãy tìm hai phần tử đó.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums = [1,2,1,3,2,5]
<strong>Đầu ra:</strong> [3,5]
<strong>Giải thích: </strong> [5, 3] is also a valid answer.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums = [-1,0]
<strong>Đầu ra:</strong> [-1,0]
</pre>

<p><strong class="example">Ví dụ 3:</strong></p>

<pre>
<strong>Đầu vào:</strong> nums = [0,1]
<strong>Đầu ra:</strong> [1,0]
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>2 &lt;= nums.length &lt;= 3 * 10<sup>4</sup></code></li>
	<li><code>-2<sup>31</sup> &lt;= nums[i] &lt;= 2<sup>31</sup> - 1</code></li>
	<li>Each integer in <code>nums</code> will appear twice, only two integers will appear once.</li>
</ul>

</div>

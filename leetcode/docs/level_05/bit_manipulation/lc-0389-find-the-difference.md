## 📋 Đề bài

<div class="lc-description"><p>Cho hai chuỗi <code>s</code> và <code>t</code> với <code>t</code> là <code>s</code> xáo trộn và thêm một chữ cái, hãy tìm chữ cái thêm vào.</p>

<p>&nbsp;</p><p><strong class="example">Ví dụ 1:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;abcd&quot;, t = &quot;abcde&quot;
<strong>Đầu ra:</strong> &quot;e&quot;
<strong>Giải thích:</strong> &#39;e&#39; is the letter that was added.
</pre>

<p><strong class="example">Ví dụ 2:</strong></p>

<pre>
<strong>Đầu vào:</strong> s = &quot;&quot;, t = &quot;y&quot;
<strong>Đầu ra:</strong> &quot;y&quot;
</pre>

<p>&nbsp;</p>
<p><strong>Ràng buộc:</strong></p>

<ul>
	<li><code>0 &lt;= s.length &lt;= 1000</code></li>
	<li><code>t.length == s.length + 1</code></li>
	<li><code>s</code> and <code>t</code> consist of lowercase English letters.</li>
</ul>

</div>
